I learned that NAT and Bridged networking are two different ways for a virtual machine to connect to a network.

NAT allows the virtual machine to access the internet through the host computer's network connection. It is a simpler option because the virtual machine does not need to appear as a separate device on the network. Bridged networking allows the virtual machine to connect directly to the same network as the host computer. It gets its own IP address and can communicate with other devices on that network. The main difference is that NAT shares the host computer's network connection, while Bridged networking allows the virtual machine to behave more like a separate computer on the network.

There are different ways to use and install software, including SaaS, binaries, repositories and source code. SaaS allows users to access software through the internet without installing the full application on their computer. Binaries are already compiled programs that users can download and run. Repositories allow users to install software through a package manager. For example, I used sudo apt install vlc in Ubuntu to install VLC. Source code is the original program code, which can be compiled into an executable program. Each method has its own advantages and disadvantages. SaaS is convenient because users can access software through a browser, but it depends on an internet connection. Binaries are easier to install because users do not need to compile the program themselves, although compatibility problems may occur. Repositories make installation and updates easier, but some software versions may not be the latest. Source code allows users and developers to examine and modify the program, but compiling it requires more technical knowledge and time. From a developer's perspective, SaaS makes it easier to manage updates centrally, while binaries allow developers to distribute ready-to-use applications. Repositories help developers distribute and maintain software packages. Source code also allows other developers to study the program, make changes and contribute improvements.
